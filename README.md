# Sobre o Projeto
O usuário possui um terreno e um orçamento limitado, então deve gerenciar os recursos de forma eficiente para aumentar a cidade.

# Configurações que o jogo possui
* [ ] Mapa
* [ ] Dinheiro, quantidade populacional
* [ ] Nível: quanto mais o usuário constrói, maior é o seu progresso de nível
* [ ] XP: mede o progresso_personagem, permitindo o desbloqueio de habilidades
* [ ] Tipos de construção permitidos: casa, fazenda, elevador, silo, cachoeira e palácio
* [ ] Tipo_sistema: PyGame
